계정 정보 처리 안내

시행일 2026년 10월 20일 · 안내 버전 2026-10-20-v1

계정에 필요한 정보

닉네임, 비밀번호의 안전한 해시와 개별 솔트, 복구 코드의 해시, 임의 계정 식별자, 가입·변경 시각, 로그인 세션과 인증 실패 횟수를 처리합니다. 목적은 회원 가입, 로그인, 닉네임 유지, 계정 복구, 본인 대회의 운영 권한 확인과 부정 접속 방지입니다. 실명·이메일·전화번호를 입력 항목으로 요구하지 않습니다.

계정 기능을 제공하는 데 필요한 정보를 처리하며 별도의 광고·마케팅 동의를 요구하지 않습니다. 계정 가입 없이도 기존 게스트 대국과 관전을 이용할 수 있습니다.

저장 위치와 전달

지속 보관하는 계정 원장은 운영자의 맥미니에 있는 별도 SQLite DB입니다. 비밀번호는 복호화할 수 없는 scrypt 해시로 저장합니다. 가입·로그인 요청과 응답은 브라우저와 맥미니 사이에서 암호화되며, 기존 공개 서버는 암호문을 임시 중계합니다.

화면은 GitHub Pages, 공개 대회·중계 서버는 ChatGPT Sites의 호스팅 기반을 이용합니다. 중계 서버에는 계정 요청·응답 암호문, 임시 요청 식별자, 만료 시각, 로그인 무효화 정보와 접속 제한용 해시를 처리합니다. 인프라 제공자는 서비스 제공 과정에서 접속 IP 등 통신 정보를 처리할 수 있습니다.

대회 참가 시 닉네임은 해당 대회의 다른 참가자와 권한 있는 관전자에게 표시됩니다. 대회 운영에 필요한 참가 당시 닉네임과 대국 결과 사본은 공개 대회 서버에 대회 유효기간 동안 보관됩니다. 장기 계정 원장과 대회 사본은 별도입니다.

보관 기간과 삭제

  • 닉네임·인증 해시 등 계정 원장은 회원 탈퇴 시 삭제합니다.
  • 로그인 세션은 최대 8시간 유효하며, 로그아웃·비밀번호 변경·탈퇴로 무효화할 수 있습니다. 무효화 전달 확인 자료는 기존 세션의 만료 시각까지 보관하며 후속 작업 때 정리합니다.
  • 계정 요청·응답의 임시 중계 유효기간은 60초입니다. 만료 자료는 후속 정리 요청 때 삭제됩니다.
  • 맥미니의 암호화된 작업 처리 확인 자료는 중복 처리 방지를 위해 최대 10분 유효하며 후속 작업 때 정리합니다. 인증 실패 제한 자료는 15분 후 정리 대상이 됩니다.
  • 대회 유효기간은 생성 후 6시간입니다. 만료된 대회 사본은 후속 정리 요청 때 삭제됩니다. 탈퇴 후에도 참가 당시 대회 기록은 해당 기간까지 남을 수 있습니다.

브라우저 보관과 계정 관리

로그인 토큰과 닉네임 등 현재 로그인 상태는 해당 탭의 sessionStorage에 보관합니다. 서비스는 비밀번호와 복구 코드를 브라우저 저장소에 저장하지 않습니다. 브라우저나 별도 비밀번호 관리자의 저장 기능은 사용자가 직접 선택합니다.

운영 페이지의 계정 설정에서 닉네임·비밀번호 변경, 복구 코드 재발급, 로그아웃과 회원 탈퇴를 직접 요청할 수 있습니다. 계정 변경과 삭제는 이 계정 설정을 이용해 주세요.

패보 저장과 리플레이

완료한 국의 패보는 다시 보기와 파일 내보내기를 위해 이 브라우저의 IndexedDB에 저장합니다. 로컬 연습 패보에는 배패와 행동 기록이 포함됩니다. 패보실에서 개별 기록을 삭제할 수 있으며, 브라우저 저장 데이터를 지우면 이 사본도 삭제됩니다. 내려받은 파일은 사용자가 직접 보관·삭제합니다.

온라인·Mortal 연습의 완료 기록은 대국 재생을 위해 별도 서버 보관소에 최대 30일간 보관합니다. 참가 당시 닉네임·자리·대회 및 국 번호·규칙·행동과 종료 결과, 접근 권한 확인 자료가 포함됩니다. 만료한 기록은 조회할 수 없으며 후속 정리 때 삭제합니다. 대회 접속 정보 또는 본인 계정으로 허용된 기록에만 접근할 수 있고, 관전자는 기존 공개 범위·지연·공개 시점을 따릅니다. 브라우저와 내보내기 파일에는 권한에 맞춘 화면만 전달하며, 서버의 패산 시드와 인증 정보는 전달하지 않습니다. 브라우저 사본 삭제와 서버 보관 기간은 별개입니다.
