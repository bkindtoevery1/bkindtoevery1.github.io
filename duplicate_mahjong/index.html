영상패와 왕패

깡 보충패는 항상 본인 패산의 다음 패입니다. 왕패를 켜면 14장을 제외합니다. 왕패 없이 도라·우라도라를 켜면 표시패용으로 2장, 깡도라를 켜면 10장을 제외합니다. 모두 끄면 136장을 전부 사용합니다.

같은 패, 다른 선택.

설정 탭의 행동 표시·소리·진동은 내 브라우저에만 적용됩니다. 연습 규칙과 방 만들기 규칙은 따로 저장되며, 참가한 방의 공통 규칙은 변경할 수 없습니다.

다른 테이블의 같은 자리는 같은 배패와 같은 개인 패산으로 시작합니다. 치·퐁으로 다른 사람의 쯔모 순서가 바뀌지 않아요.

혼자 연습에서는 동일 배패의 AI 기준 대국과 비교합니다. 온라인에서는 같은 대회·같은 국·같은 자리의 완료된 사람 참가자들끼리 평균 대비 점수를 비교합니다. 비교 대상이 2명 미만이면 평균은 아직 표시하지 않습니다.

각 국의 점수는 독립적으로 계산하고 친은 순서대로 바뀝니다. 유국 시 텐파이 벌점 3,000점을 정산합니다. 리치 공탁은 화료자가 받고, 유국에 남은 공탁은 다음 국으로 넘기지 않습니다.

기본 역·부 계산을 지원하며, 유국 중 사깡산료만 설정할 수 있습니다. 구종구패·사풍연타·사리치·삼가화·유국만관과 국사무쌍의 안깡 창깡은 현재 포함하지 않습니다.

기본 AI는 샨텐·유효패를 사용하는 로컬 상대입니다. Mortal은 공개 커뮤니티 학습 v3 모델을 사용하며 서버 연결이 필요합니다. 우리 규칙으로 추가 학습하는 모델은 별도로 검증 중입니다. 연습 결과의 기준 대국은 기본 AI로 계산합니다.
