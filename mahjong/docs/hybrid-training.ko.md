# 공격·수비 혼합형과 역패 평가 수정

## 무엇을 고쳤는가

기존 G 계열은 기본 역 점수 100점을 경계로 위험 가중치를 바꿨다. 새 M 계열은 손의 완성도·유효패·가산을 포함한 점수·아직 화료하지 않은 상대 수·공개 위협을 함께 평가한다. 가까운 고득점 손에는 공격 비중이 커지고, 멀고 낮은 손에서 상대의 공개 위협이 커지면 수비 비중이 커진다. 론과 쯔모는 수락한다. 패보 데이터나 LLM 호출로 학습한 것이 아니라, 로컬 자동 대국에서 휴리스틱 가중치를 비교한 것이다.

기존 자패 평가식은 같은 역패를 **0장 보유한 경우와 1장 보유한 경우 모두 단가의 5%**로 평가했다. 따라서 마지막 한 장을 버려도 그 항목의 가치가 줄지 않았다. 또한 대자에 남은 두 장이 모두 공개돼도 단가의 45%가 유지됐다. 새 `honorModel:1`은 없는 패를 0점, 고립패·대자는 미확인 잔여 장수와 남은 기회를 반영한 잠재 가치, 완성 커쯔·깡쯔는 실제 가산으로 구분한다.

예를 들어 동장·동가의 `12345m456p789s156z`에서 기존 D/E는 동·백·발을 같은 가치로 취급하고 순서상 동을 먼저 버렸다. 새 모델은 다른 조건이 같으면 연풍패 동의 단가 200점을 백·발 각 100점과 구분한다. 이것이 모든 역패를 끝까지 보유해야 한다는 뜻은 아니다. 한 장짜리 역패는 두 장을 더 모아야 하고, 추가 패가 이미 공개됐다면 수패 연결을 살리는 선택이 유리할 수 있다.

H 문의 답변의 가산 규칙은 변경하지 않았다. 번패는 커쯔·깡쯔일 때 항목당 100점, 연풍패는 200점이다. 역패 머리·한 장만으로 가산하지 않는다. 역패 가산과 쯔모 보너스는 서로 다른 항목이다.

## 비교와 앱 적용

- A, D, E: 기존 전략.
- V1: 이전 실험에서 고정한 고득점형. 기존 판단식을 그대로 보존한다.
- Y1: V1에 자패 평가만 수정한 비교군.
- M1: 속도를 중시하는 공격·수비 혼합형.
- M2: 고득점을 중시하는 공격·수비 혼합형.
- M3: 수비 가중치를 더 높인 공격·수비 혼합형.

각 M 계열의 두 후보를 튜닝 시드에서 비교하고 하나씩 고정한다. 이 세 버전 중 튜닝 평균이 가장 높은 버전을 **최종 검증 전에** 기본 혼합형으로 정한다. 기본 선택은 사용자의 혼합형 사용 요청에 따른 것이며, 검증 우위 확인과 구분한다. 검증 결과로 다시 가중치나 기본 버전을 바꾸지 않는다.

앱 상단 **H룰 전략 버전**에서 선택한다. 해당 부모 정책의 추천과 내 자리 자동 대국에 적용되며 상대 AI 구성은 고정한다. M은 E 자리를, Y1은 D 자리를 대신한다. 다른 A–E 추천과 기존 V/G는 비교용으로 남겨 둔다. 처음 새 버전을 여는 경우 혼합형을 기본 선택하며, 이후의 명시 선택은 기기에 저장한다. 상대 AI 전체나 4인 친선전 빈자리 AI를 새 모델로 변경한 것은 아니다.

실험은 동장 H-2026-private-kan-v1의 단일 국이다. 규칙값이 다르거나 S룰·H 남장인 경우 현재 호환성 검사에 따라 기본 전략으로 돌아가며 화면에 표시한다. 남장·반장 최종 순위나 사람 상대 우위는 별도 검증하지 않았다. 안깡 전체 비공개는 사용자 요청 앱 설정이며 원문에서 확정한 규정으로 주장하지 않는다.

## 판단식과 한계

텐파이 후보는 공개 정보상 아직 남아 있는 대기를 기준으로 실제 론 점수와 쯔모 수령액을 계산한다. 남은 대기 장수로 평균하며 공개상 전부 소진된 대기에 높은 점수를 부여하지 않는다. 텐파이 전의 역 가치는 형태 추정이다. 미확인 패에는 상대 손패도 포함되므로 패산에 실제로 남은 장수나 정밀 확률은 아니다.

상대의 버림패 수·부로 수·공개된 역패와 수패 치우침에서 위협을 추정한다. 이미 화료한 상대는 제외하고, 비공개 안깡의 종류는 읽지 않는다. H에는 기본 후리텐이 없으므로 과거 버림패를 절대 안전패로 처리하지 않는다. 같은 수패 네 장이 알려져 있어도 다른 두 패와 슌쯔로 론할 가능성은 고려한다. 이 위험도는 통계적으로 보정된 방총 확률이 아니다.

깡은 미확인 보충패 후보별 다음 버림패까지 평가하여, 깡을 하면 위험 감점이 사라지는 문제를 줄였다. 실제 패산 뒤쪽은 보지 않는다. 다만 보충패 즉시 쯔모의 선택 효용은 `speed + value × 화료점 × (0.6 + 미화료자수/5)`라는 휴리스틱이다. 이 가지에는 실제 쯔모 보너스와 지급자 수를 직접 곱하지 않는다. 이는 전략 평가의 한계이며 **실제 점수 정산은 엔진의 정확한 가산·지급 규칙을 사용**한다. 위험도·효용·공격 비중은 강화학습 Q값이나 확률이 아니다.

## 재현

```sh
node training/hybrid-run.mjs
node training/hybrid-run.mjs --execute --pilot-only
node training/hybrid-run.mjs --execute
node training/hybrid-export.mjs
python3 scripts/audit_hybrid.py
```

첫 명령은 계획만 출력한다. 실행 중 Ctrl+C 후 같은 명령으로 재개하며 코드·설정 해시가 바뀌면 재개를 거절한다. 오류가 나면 실패 패보를 해당 하위 실험의 failures에 저장한다.

여섯 상대 성향을 같은 비중으로 배정한다. 검증 504개 시드 각각에서 네 자리와 여덟 정책을 짝지어 비교한다. 신뢰구간은 상대 성향을 층으로 나누고 **동일 시드의 네 자리·모든 정책을 한꺼번에** 재추출하는 10,000회 부트스트랩으로 계산한다. M1/M2/M3 대 V1/Y1의 여섯 비교는 각각 99.1667% 구간으로 보정한다. 그 외 정책 쌍·성향별 95% 구간은 탐색용이다. 새 분석기 RNG는 매 회 32비트로 순환하며 이전 실험 결과는 덮어쓰지 않는다.
