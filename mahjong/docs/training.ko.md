# A–E 추가 학습 실행 안내

이번 학습은 새로운 시드로 실제 H룰 자동 대국을 진행하면서 휴리스틱의 가중치를 고르는 과정이다. 신경망 학습이나 다른 이용자의 패보를 학습 데이터로 사용하는 기능은 아니다. 대국 중 LLM·API 호출은 없다.

## 실행과 재개

```bash
npm run train:plan
npm run train
npm run train:status
npm run train:report
```

첫 명령은 설정된 국 수와 기존 실측 속도에 따른 예상 시간만 출력한다. 두 번째는 `configs/training-20261006.json`의 계획을 실행한다. `Ctrl+C`로 중단하고 같은 명령으로 재개할 수 있다. 완료된 국과 완료된 후보를 재사용한다. 설정·엔진이 달라진 폴더는 재개하지 않는다. 실행 중 `training/run.mjs`·`training/analyze.mjs`를 수정하지 않는다. 이 두 파일과 설정의 SHA-256도 완료 후 `provenance.json`에 기록한다.

`train:status`는 다른 터미널에서 전체 완료 국 수·단계·예상 남은 시간을 확인하는 명령이다. `train:report`는 완료된 실험만 보고서와 앱 가중치로 내보낸다. 미완료 결과나 근거 해시가 다른 결과는 거절한다. 실행 결과는 `results/training-20261006/`에 저장한다. 원본 10,000국 결과는 `results/baseline/`에 보존한다.

## 시드 분리와 비교

|단계|시드|용도|
|---|---|---|
|100국 점검|30000000–30000004|오류·속도 점검, 학습 제외|
|후보 선별|31000000–31000249|A 9개, B/C 공동 9개, D 9개, E 27개 후보|
|추가 확인|31000250–31000999|각 그룹의 기본값과 상위 후보 2개 재확인|
|최종 검증|32000000–32001999|가중치 동결 후 기존·학습 후보 A–E 비교|

각 시드는 최속·핑후·고득점·신중·혼합 중 한 상대 성향을 사용한다. 다섯 성향의 비중은 같다. 같은 시드의 네 자리, A–E, 기존·학습 후보가 같은 초기 패산과 기존 상대 구성을 사용한다. 성향별로 시드 묶음을 재표본해 평균과 차이의 신뢰구간을 구한다.

B와 C는 동일한 가중치를 고른다. C는 기존 정의대로 합법적으로 넘길 수 있는 모든 론을 거절한다. 상황별로 론을 골라 넘기는 새 전략까지 학습한 것은 아니다.

## 앱 적용

H룰의 **전략 버전**에서 기존 A–E와 추가 학습 버전을 선택한다. 내 추천과 자동 대국에 함께 적용하며 상대 AI는 검증 때 사용한 기존 정의를 유지한다. S룰은 별도 정책을 사용한다.

가중치가 바뀌고, 독립 검증의 기존 대비 차이에서 99% 신뢰구간 하한이 0보다 큰 정책만 적용한다. 다섯 개의 개선 비교를 보정한 기준이다. B와 C는 둘 다 통과해야 함께 적용한다. 선택된 학습 후보라도 기준을 통과하지 못하면 앱은 해당 정책의 기존 가중치를 쓴다.

## 다음 실험

이 검증 결과를 보고 탐색 범위나 론 거절 조건을 바꾸면, 이번 검증 시드는 이후 튜닝 자료가 된다. 다음 최종 검증에는 새로운 겹치지 않는 시드 범위를 사용한다. 계획 파일의 ID·출력 폴더·시드 범위를 새로 지정하고, 먼저 `node training/run.mjs --plan <새 설정>`으로 필요한 국 수와 예상 시간을 제시한 뒤 실행한다. 이번 결과가 전역 최적 전략을 증명하지는 않는다.

H의 멘젠·핑후·쯔모 지급·치또이츠 네 장 처리 등 규칙 가정은 기존 실험과 같다. [규칙 문서](rules-audit.ko.md)와 완료된 [추가 학습 보고서](../results/training-20261006/report.ko.md)를 함께 확인한다.
