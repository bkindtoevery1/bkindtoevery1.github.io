# H룰 규칙 검증과 적용 가정

## 자료와 검증 범위

「第五届世界活力麻将公开赛指南」의 중국어·일본어 H §8.2.1 및 점수표 §8.2.2를 기준으로 작성했습니다. 원본 자료는 공개 배포에 포함하지 않습니다.

기존 연습 앱의 소스는 확보하지 못했으므로 기존 안깡 오류의 원인은 확인되지 않았습니다. 새 엔진에서는 손패의 동일패 네 장, 자기 차례, 보충패가 있는 경우 안깡을 제공하며 회귀 테스트로 검증했습니다. 기존 앱 오류를 재현했다는 뜻은 아닙니다.

## 명확한 조항

1. 한 사람이 화료해도 국은 계속한다. 세 번째 화료 또는 유국에서 종료한다.
2. 론은 방총자 혼자 화료점 전액을 지급한다. 쯔모는 아직 화료하지 않은 다른 사람마다 지급한다.
3. 이미 화료한 사람은 이후 행동·론·쯔모 지급·유국 정산에서 빠진다.
4. 최고 점수의 단일 역 하나만 취한다. 깡·삼원패·장풍·자풍만 가산 가능하다.
5. 유국 시 미화료 노텐자가 미화료 텐파이자에게 텐파이 손의 최고 역 점수를 지급한다.
6. 쯔모는 각 지급자에게 역 점수 외에 1번 상당을 더 받는다. 표의 1번=100점으로 구현했다.

중국어·일본어와 영어가 다르면 중국어·일본어를 우선했다. 예를 들어 영어에는 세 번째 화료 때 텐파이 검사 문구와 ‘세 상대’ 쯔모 문구가 있으나, 본문 중·일문은 유국 검사 및 미화료자 지급이다. 손패 크기·배패(13장씩, 친 14장)·치/퐁/깡의 형태·콜 우선순위(론, 퐁/깡, 치)는 보충 진행 규칙이다. 랜덤하게 섞은 136장 순서를 개문 후 소비 순서로 정의한다. 개문 위치의 다국어 7/8번째 차이는 이 균등 셔플 실험의 배분에 영향을 주지 않는다.

론 화료에 사용된 버림패는 강의상의 여러 손에 복제하지 않고 강물에 물리적으로 한 장 남기며 화료 기록이 그 패를 참조한다. 퐁·치·명깡은 강물의 해당 패를 소비한 공개 몸통으로 옮긴다. 깡을 해도 패를 새로 생성하지 않는다. 각 정책에는 패 ID·시드·타인 비공개 손패·실제 패산 순서를 주지 않는다. 후리텐이 없는 기본 H에서 한 번 버린 패를 절대 안전패로 간주하지 않는다.

## 검증 방법

`npm test`는 H 표의 모든 역, 중복 해석 가능한 분해, 화료 후 이탈, 쯔모 지급자 수, 복수 론, 유국, 안깡, 가깡, 불법 행동, 보존, 공개 관측 경계, 재현성을 확인한다. 본 시뮬레이션도 모든 행동 뒤 불변식을 검사한다. 첫 100국은 오류·속도 점검용 별도 시드이며 본 분석에는 섞지 않는다. 실패 시 해당 시드·행동 기록·상태를 `failures/*.json`으로 보존한다.

결과는 이 가정 아래의 실험이다. 미확정 규칙이 바뀌면 다른 결과가 나올 수 있으며, 기본 시나리오 결과만으로 실제 대회에서의 우월성을 확정하지 않는다.
